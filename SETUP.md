# Configuración de GitHub Pages

Este repositorio está configurado para publicarse con GitHub Pages y Just-the-Docs.

## Publicación

En GitHub:

1. Entrar al repositorio.
2. Ir a `Settings`.
3. Abrir `Pages`.
4. En `Build and deployment` seleccionar `Deploy from a branch`.
5. Elegir rama `main`.
6. Elegir carpeta `/ (root)`.
7. Guardar.

La dirección esperada es:

`https://vmolvera.github.io/Proyecto-Pendulo-Invertido-/`

## Importante

El valor actual de `baseurl` en `_config.yml` coincide con el nombre actual del repositorio:

`Proyecto-Pendulo-Invertido-`

Si se cambia el nombre del repositorio, también se debe actualizar `baseurl`.
