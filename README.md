# Proyecto Péndulo Invertido — QUBE-Servo 3

Repositorio del proyecto de Control Avanzado para el modelado, análisis, diseño e implementación de un controlador para un péndulo invertido utilizando la plataforma QUBE-Servo 3.

## Contenido

- Modelo matemático
- Representación en espacio de estados
- Análisis de estabilidad
- Controlabilidad
- Control LQR
- Observador de estados
- Implementación en Simulink
- Análisis en frecuencia
- Resultados experimentales
- Conclusiones
